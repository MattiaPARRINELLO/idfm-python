## 🎯 Présentation
Application de bureau qui affiche en temps réel les départs de train pour une gare donnée en Île-de-France. Interface graphique moderne avec customtkinter, suggestions de stations, et données en direct via lAPI IDF Mobilités.

---

## ✨ Fonctionnalités
- ✅ Recherche de gare avec autocomplétion
- ✅ Affichage temps réel des prochains départs
- ✅ Numéro de voie et temps dattente
- ✅ Interface moderne (customtkinter)
- ✅ Mode clair/sombre

---

## 🚀 Installation
```bash
git clone https://github.com/MattiaPARRINELLO/IDFM-Python.git
cd IDFM-Python
pip install -r requirements.txt
# Créez un fichier .env avec votre clé API IDF Mobilités
python main.py
```
